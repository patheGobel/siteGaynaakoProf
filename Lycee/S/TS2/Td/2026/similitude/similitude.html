Exercice 1

Dans chacun des cas suivants, déterminer l'écriture complexe de la similitude directe de centre $\Omega$, de rapport $k$ et d'angle $\theta$.

  1. $\Omega = O$, $k = 2$ et $\theta = \dfrac{\pi}{6}$.
  2. $\Omega \begin{pmatrix} 1 \\ 0 \end{pmatrix}$, $k = \sqrt{2}$ et $\theta = \dfrac{\pi}{2}$.
  3. $\Omega \begin{pmatrix} 2 \\ -1 \end{pmatrix}$, $k = 1$ et $\theta = \dfrac{5\pi}{6}$.
  4. $\Omega (-2 + i\frac{1}{2})$, $k = \dfrac{1}{2}$, $\theta = \dfrac{-\pi}{3}$.
Voir la solution

Rappel : L'écriture complexe d'une similitude directe de centre $\Omega$ d'affixe $\omega$, de rapport $k$ et d'angle $\theta$ est :

$$z' - \omega = k e^{i\theta}(z - \omega)$$

1. $\omega = 0$, $z' = 2e^{i\frac{\pi}{6}}z = (\sqrt{3} + i)z$

$\boxed{z' = (\sqrt{3} + i)z}$

2. $\omega = 1$, $z' - 1 = \sqrt{2}e^{i\frac{\pi}{2}}(z - 1) = \sqrt{2}i(z - 1)$

$\boxed{z' = \sqrt{2}i z - \sqrt{2}i + 1}$

3. $\omega = 2 - i$, $z' - (2 - i) = e^{i\frac{5\pi}{6}}(z - (2 - i))$

$e^{i\frac{5\pi}{6}} = -\frac{\sqrt{3}}{2} + \frac{1}{2}i$

$\boxed{z' = (-\frac{\sqrt{3}}{2} + \frac{1}{2}i)z + \omega(1 - e^{i\frac{5\pi}{6}})}$

4. $\omega = -2 + \frac{1}{2}i$, $z' - \omega = \frac{1}{2}e^{-i\frac{\pi}{3}}(z - \omega)$

$e^{-i\frac{\pi}{3}} = \frac{1}{2} - i\frac{\sqrt{3}}{2}$

$\boxed{z' = \frac{1}{2}e^{-i\frac{\pi}{3}}z + \omega(1 - \frac{1}{2}e^{-i\frac{\pi}{3}})}$

Exercice 2

Dans chacun des cas suivants, déterminer la nature et les éléments caractéristiques de l'application $f$ du plan dans lui-même, qui au point $M$ d'affixe $z$ associe le point $M'$ d'affixe $z'$ :

a. $z' = (\sqrt{3} + i)z$

b. $z' = -2z + i$

c. $z' = -z + 2i$

d. $z' = \dfrac{3 + i\sqrt{3}}{4}z + \dfrac{1 - i\sqrt{3}}{2}$

e. $z' = iz + 1$

f. $z' = z + 3 - i$

Voir la solution

a. $z' = (\sqrt{3} + i)z$

$|a| = \sqrt{3 + 1} = 2$, $a = 2e^{i\frac{\pi}{6}}$

$\boxed{\text{Similitude directe de centre }O\text{, rapport }2\text{, angle }\frac{\pi}{6}}$

b. $z' = -2z + i$, $a = -2 = 2e^{i\pi}$

Point fixe : $\omega = \dfrac{i}{1 - (-2)} = \dfrac{i}{3}$

$\boxed{\text{Similitude directe de centre }\omega = \frac{i}{3}\text{, rapport }2\text{, angle }\pi}$

c. $z' = -z + 2i$, $a = -1 = e^{i\pi}$

Point fixe : $\omega = \dfrac{2i}{1 - (-1)} = i$

$\boxed{\text{Similitude directe de centre }\omega = i\text{, rapport }1\text{, angle }\pi}$

d. $z' = \dfrac{3 + i\sqrt{3}}{4}z + \dfrac{1 - i\sqrt{3}}{2}$

$a = \dfrac{3 + i\sqrt{3}}{4} = \dfrac{\sqrt{3}}{2}e^{i\frac{\pi}{6}}$

Point fixe : $\omega = \dfrac{b}{1 - a}$

e. $z' = iz + 1$, $a = i = e^{i\frac{\pi}{2}}$

Point fixe : $\omega = \dfrac{1}{1 - i} = \dfrac{1 + i}{2}$

$\boxed{\text{Similitude directe de centre }\omega = \frac{1+i}{2}\text{, rapport }1\text{, angle }\frac{\pi}{2}}$

f. $z' = z + 3 - i$, $a = 1$

$\boxed{\text{Translation de vecteur }3 - i}$

Exercice 3

Dans chacun des cas suivants, déterminer l'écriture complexe de la similitude directe $s$ définie par : $S(A) = A'$ et $S(B) = B'$.

  1. $A(3+2i), A'(3), B(1)$ et $B'(i)$;
  2. $A(2+i), A'(3+2i), B(2)$ et $B'(3i)$.
Voir la solution

Rappel : Une similitude directe s'écrit $z' = az + b$ avec $a \in \mathbb{C}^*$.

a. $A(3+2i) \to A'(3)$, $B(1) \to B'(i)$

$a = \dfrac{z'_{A} - z'_{B}}{z_A - z_B} = \dfrac{3 - i}{(3+2i) - 1} = \dfrac{3 - i}{2 + 2i} = \dfrac{(3-i)(2-2i)}{8} = \dfrac{6 - 6i - 2i + 2i^2}{8} = \dfrac{4 - 8i}{8} = \dfrac{1}{2} - i$

$b = z'_{A} - a z_A = 3 - (\dfrac{1}{2} - i)(3+2i) = 3 - (\dfrac{3}{2} + i - 3i - 2i^2) = 3 - (\dfrac{3}{2} - 2i + 2) = 3 - \dfrac{7}{2} + 2i = -\dfrac{1}{2} + 2i$

$\boxed{z' = (\dfrac{1}{2} - i)z - \dfrac{1}{2} + 2i}$

b. $A(2+i) \to A'(3+2i)$, $B(2) \to B'(3i)$

$a = \dfrac{(3+2i) - 3i}{(2+i) - 2} = \dfrac{3 - i}{i} = \dfrac{3 - i}{i} = \dfrac{3}{i} - 1 = -3i - 1 = -1 - 3i$

$b = z'_{A} - a z_A = (3+2i) - (-1-3i)(2+i) = 3+2i - (-2 - i - 6i - 3i^2) = 3+2i - (-2 - 7i + 3) = 3+2i - (1 - 7i) = 2 + 9i$

$\boxed{z' = (-1 - 3i)z + 2 + 9i}$

Exercice 4

Soit $s$ la similitude directe d'écriture complexe : $z' = 3iz - 9 - 3i$.

  1. Déterminer les éléments caractéristiques de $s$.
  2. Déterminer l'expression analytique de $s$.
  3. Déterminer l'image par $s$ :
    1. du cercle de centre $K(1 - 3i)$ et de rayon 1;
    2. de la droite $(\mathscr{D})$ d'équation : $x = 1$;
    3. de la droite passant par le point $A(5;3)$ et dont un vecteur directeur est $\vec{u}(-1;3)$.
Voir la solution

1. $z' = 3iz - 9 - 3i$

$a = 3i = 3e^{i\frac{\pi}{2}}$

Rapport : $k = 3$, angle : $\theta = \dfrac{\pi}{2}$

Point fixe : $\omega = \dfrac{b}{1 - a} = \dfrac{-9 - 3i}{1 - 3i} = \dfrac{(-9-3i)(1+3i)}{10} = \dfrac{-9 - 27i - 3i - 9i^2}{10} = \dfrac{0 - 30i}{10} = -3i$

$\boxed{\text{Centre }\omega = -3i\text{, rapport }3\text{, angle }\frac{\pi}{2}}$

2. $z = x + iy$, $z' = x' + iy'$

$z' = 3i(x+iy) - 9 - 3i = 3ix - 3y - 9 - 3i = (-3y - 9) + i(3x - 3)$

$\boxed{\begin{cases} x' = -3y - 9 \\ y' = 3x - 3 \end{cases}}$

3.a) Image d'un cercle : cercle de centre $K' = s(K)$ et rayon $k \times r = 3$

$K(1 - 3i)$ : $z'_K = 3i(1-3i) - 9 - 3i = 3i - 9i^2 - 9 - 3i = 3i + 9 - 9 - 3i = 0$

$\boxed{\text{Cercle de centre }O\text{ et de rayon }3}$

3.b) Image d'une droite : droite passant par $s(A)$ de direction $s(\vec{u})$

$A(1)$ : $z'_A = 3i(1) - 9 - 3i = 3i - 9 - 3i = -9$

Direction verticale car $s$ est une rotation + homothétie

$\boxed{\text{Droite }x = -9}$

Exercice 5

Soit $A, B$ et $C$ les points d'affixes respectives : $i, 1 + i$ et $2 + 2i$.

  1. Déterminer l'affixe du barycentre $G$ des points $A, B$ et $C$ affectés respectivement des coefficients $2, -2$ et $1$.
  2. Démontrer que la similitude directe $s$, qui transforme $A$ en $B$ et $B$ en $C$, a pour centre le point $G$.
  3. Déterminer l'angle et le rapport de $s$.
Voir la solution

1. $z_G = \dfrac{2z_A - 2z_B + z_C}{2 - 2 + 1} = 2(i) - 2(1+i) + (2+2i) = 2i - 2 - 2i + 2 + 2i = 2i$

$\boxed{G(2i)}$

2. $s$ est définie par $z' = az + b$ avec $s(A) = B$ et $s(B) = C$.

$a = \dfrac{z_C - z_B}{z_B - z_A} = \dfrac{(2+2i) - (1+i)}{(1+i) - i} = \dfrac{1+i}{1} = 1 + i$

$b = z_B - a z_A = (1+i) - (1+i)i = 1+i - (i + i^2) = 1+i - i + 1 = 2$

Vérifions que $G$ est le centre : $z_G = \dfrac{b}{1 - a} = \dfrac{2}{1 - (1+i)} = \dfrac{2}{-i} = 2i$

$\boxed{\text{Le centre de }s\text{ est bien }G}$

3. $a = 1 + i = \sqrt{2}e^{i\frac{\pi}{4}}$

$\boxed{\text{Rapport }k = \sqrt{2}\text{, angle }\theta = \frac{\pi}{4}}$

Exercice 6 BAC

On considère les applications $T_1$ et $T_2$ dont les écritures complexes sont :
$T_1 : z_1 = (\sqrt{3} + i)z$ et $T_2 : z_2 = (1 - i\sqrt{3})z + 3$.

  1. Déterminer la nature et les éléments caractéristiques de $T_1$ et $T_2$.
  2. Déterminer l'écriture complexe, la nature et les éléments caractéristiques de $T_2 \circ T_1$.
  3. Démontrer qu'il existe un seul point $K$ tel que $T_1(K) = T_2(K)$. Soit $L = T_1(K)$. Calculer les affixes des points $K$ et $L$.
  4. Démontrer que le point $L$ est invariable pour chacune des applications $T_2 \circ T_1^{-1}$ et $T_1 \circ T_2^{-1}$.
  5. Déterminer l'écriture complexe de chacune des applications $T_2 \circ T_1^{-1}$ et $T_1 \circ T_2^{-1}$. Préciser leurs natures et éléments caractéristiques.
Voir la solution

1. $T_1 : z_1 = (\sqrt{3} + i)z = 2e^{i\frac{\pi}{6}}z$

$\boxed{T_1 : \text{similitude directe de centre }O\text{, rapport }2\text{, angle }\frac{\pi}{6}}$

$T_2 : z_2 = (1 - i\sqrt{3})z + 3 = 2e^{-i\frac{\pi}{3}}z + 3$

Point fixe : $\omega = \dfrac{3}{1 - 2e^{-i\frac{\pi}{3}}} = \dfrac{3}{1 - (1 - i\sqrt{3})} = \dfrac{3}{i\sqrt{3}} = -i\sqrt{3}$

$\boxed{T_2 : \text{similitude directe de centre }-i\sqrt{3}\text{, rapport }2\text{, angle }-\frac{\pi}{3}}$

2. $T_2 \circ T_1 : z' = (1 - i\sqrt{3})(\sqrt{3} + i)z + 3$

$a = (1 - i\sqrt{3})(\sqrt{3} + i) = \sqrt{3} + i - 3i - i^2\sqrt{3} = \sqrt{3} + 1 - 2i$

$|a| = \sqrt{(\sqrt{3}+1)^2 + 4} = \sqrt{4 + 2\sqrt{3} + 4} = \sqrt{8 + 2\sqrt{3}}$

3. $T_1(K) = T_2(K) \iff (\sqrt{3}+i)z_K = (1 - i\sqrt{3})z_K + 3$

$(\sqrt{3}+i - 1 + i\sqrt{3})z_K = 3$

$((\sqrt{3}-1) + i(1+\sqrt{3}))z_K = 3$

$z_K = \dfrac{3}{(\sqrt{3}-1) + i(\sqrt{3}+1)}$

$L = T_1(K)$

5. $T_2 \circ T_1^{-1}$ est une similitude directe de rapport $1$ (car $T_1$ et $T_2$ ont même rapport 2).

Donc c'est une rotation d'angle $\theta_2 - \theta_1 = -\dfrac{\pi}{3} - \dfrac{\pi}{6} = -\dfrac{\pi}{2}$.

Son centre est $L$.

Exercice 7

Soit $S_1$ l'application qui à tout point $M(x,y)$ associe $M'(x',y')$ définie par :

$\begin{cases} x' = -\frac{1}{2}x - \frac{\sqrt{3}}{2}y + \frac{3}{2} \\ y' = \frac{\sqrt{3}}{2}x - \frac{1}{2}y - \frac{\sqrt{3}}{2} \end{cases}$
  1. Déterminer l'écriture complexe de $S_1$.
  2. En déduire la nature et les éléments caractéristiques de $S_1$.
  3. Soient les points $A(1)$ et $B(-1)$. Déterminer l'écriture complexe de la similitude directe $S_2$ telle que $S_2(A) = O$ et $S_2(B) = B$ puis caractériser $S_2$.
  4. On pose $S = S_1 \circ S_2$. Déterminer l'écriture complexe de $S$.
  5. Déterminer l'image par $S$ :
    1. de la droite $(\mathscr{D})$ d'équation $2x + y - 1 = 0$;
    2. du cercle $(\mathscr{C})$ d'équation $(x + 3)^2 + (y - 2)^2 = 4$.
Voir la solution

1. $z' = x' + iy' = (-\frac{1}{2}x - \frac{\sqrt{3}}{2}y + \frac{3}{2}) + i(\frac{\sqrt{3}}{2}x - \frac{1}{2}y - \frac{\sqrt{3}}{2})$

$= (-\frac{1}{2} + i\frac{\sqrt{3}}{2})x + (-\frac{\sqrt{3}}{2} - i\frac{1}{2})y + \frac{3}{2} - i\frac{\sqrt{3}}{2}$

$= (-\frac{1}{2} + i\frac{\sqrt{3}}{2})(x + iy) + \frac{3}{2} - i\frac{\sqrt{3}}{2}$

$\boxed{z' = (-\frac{1}{2} + i\frac{\sqrt{3}}{2})z + \frac{3}{2} - i\frac{\sqrt{3}}{2}}$

2. $a = -\frac{1}{2} + i\frac{\sqrt{3}}{2} = e^{i\frac{2\pi}{3}}$

Rapport $k = 1$, angle $\theta = \dfrac{2\pi}{3}$

Point fixe : $\omega = \dfrac{b}{1 - a} = \dfrac{\frac{3}{2} - i\frac{\sqrt{3}}{2}}{1 - (-\frac{1}{2} + i\frac{\sqrt{3}}{2})} = \dfrac{\frac{3}{2} - i\frac{\sqrt{3}}{2}}{\frac{3}{2} - i\frac{\sqrt{3}}{2}} = 1$

$\boxed{S_1 : \text{rotation de centre }\omega = 1\text{ et d'angle }\frac{2\pi}{3}}$

3. $S_2(A) = O$ et $S_2(B) = B$

$S_2 : z' = az + b$

$a = \dfrac{0 - (-1)}{1 - (-1)} = \dfrac{1}{2}$

$b = 0 - a \times 1 = -\frac{1}{2}$

$\boxed{S_2 : z' = \frac{1}{2}z - \frac{1}{2} = \frac{1}{2}(z - 1)}$

$\boxed{S_2 : \text{homothétie de centre }B(-1)\text{ et de rapport }\frac{1}{2}}$

Exercice 8 BAC 2024 (05 points)

1. Dans le plan complexe muni d'un repère orthonormé direct $(O; \vec{i}, \vec{j})$, on considère les points $A, B$ et $C$ d'affixes respectives : $z_A = -3i$, $z_B = -2$ et $z_C = 1 + 2i$.

  1. Déterminer le module et un argument du quotient $\dfrac{2z_C - z_B}{z_A - z_B}$. (0,75 point)
  2. En déduire la nature du triangle $ABC$. (0,75 point)
  3. Déterminer l'affixe $z_D$ du point $D$ tel que le quadrilatère $BADC$ soit un carré. (0,5 point)
  4. Montrer que les points $A, B, C$ et $D$ appartiennent à un même cercle dont on précisera le centre et le rayon. (0,75 point)

2. On considère les points $M$ et $M'$ d'affixes respectives $z = x + iy$ et $z' = x' + iy'$ où $x, y, x', y'$ sont des réels.

Soit $S$ l'application du plan dans le plan d'expression analytique : $\begin{cases} x' = x - y + 2 \\ y' = x + y - 1 \end{cases}$

  1. Montrer que l'écriture complexe de $S$ est : $z' = (1 + i)z + 2 - i$. (0,5 point)
  2. Déterminer la nature et les éléments caractéristiques de $S$. (0,5 point)
  3. Déterminer l'image par $S$ de la droite $(D)$ d'équation $x + y + 1 = 0$. (0,5 point)
  4. Déterminer l'ensemble des points $M$ dont l'affixe $z$ vérifie $|(1 + i)z + 2 - i| = 2$. (0,5 point)
Voir la solution

1.a) $\dfrac{2z_C - z_B}{z_A - z_B} = \dfrac{2(1+2i) - (-2)}{-3i - (-2)} = \dfrac{2 + 4i + 2}{2 - 3i} = \dfrac{4 + 4i}{2 - 3i}$

$= \dfrac{(4+4i)(2+3i)}{4 + 9} = \dfrac{8 + 12i + 8i + 12i^2}{13} = \dfrac{8 + 20i - 12}{13} = \dfrac{-4 + 20i}{13}$

Module : $\left|\dfrac{-4 + 20i}{13}\right| = \dfrac{\sqrt{16 + 400}}{13} = \dfrac{4\sqrt{26}}{13}$

1.b) Le triangle $ABC$ est rectangle isocèle en $B$.

1.c) $z_D = z_A + z_C - z_B = -3i + (1+2i) - (-2) = 3 - i$

1.d) Centre : $\omega = \dfrac{z_A + z_C}{2} = \dfrac{1 - i}{2}$, rayon $R = \dfrac{|z_C - z_A|}{2} = \dfrac{|1 + 5i|}{2} = \dfrac{\sqrt{26}}{2}$

2.a) $z' = x' + iy' = (x - y + 2) + i(x + y - 1) = x + iy + ix - y + 2 - i = (1+i)(x+iy) + 2 - i$

$\boxed{z' = (1+i)z + 2 - i}$

2.b) $a = 1+i = \sqrt{2}e^{i\frac{\pi}{4}}$

Point fixe : $\omega = \dfrac{2 - i}{1 - (1+i)} = \dfrac{2 - i}{-i} = i(2-i) = 2i + 1 = 1 + 2i$

$\boxed{S : \text{similitude directe de centre }\omega = 1+2i\text{, rapport }\sqrt{2}\text{, angle }\frac{\pi}{4}}$

2.c) Image de la droite $x + y + 1 = 0$

$\boxed{\text{Une droite passant par }S(A)\text{ et de direction }S(\vec{u})}$

2.d) $|(1+i)z + 2 - i| = 2 \iff |z'| = 2$

$\boxed{\text{Cercle de centre }O\text{ et de rayon }2}$

Donc $M$ appartient à l'image réciproque du cercle de centre $O$ et de rayon $2$ par $S$.

$\boxed{\text{Cercle de centre }S^{-1}(O) = \omega = 1+2i\text{ et de rayon }\frac{2}{\sqrt{2}} = \sqrt{2}}$
