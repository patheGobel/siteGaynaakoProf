Exercice 1
Forme algébrique et calcul de $i^n$
  1. Déterminer les formes algébriques des nombres complexes donnés. Préciser, le cas échéant, s'il est réel ou imaginaire pur.
    1. $z_1 = i(1 - 4i) + 3(2 - i)$
    2. $z_2 = (3 - i)^2 + 6i$
    3. $z_3 = \dfrac{3}{1 - i}$
    4. $z_4 = \dfrac{1 + 2i}{2 - i}$
    1. $z_5 = (2 + i\sqrt{3})(\sqrt{3} - i)$
    2. $z_6 = (2 + 5i)^2$
    3. $z_7 = \dfrac{3 - 3i}{1 + i}$
  2. Calculer $i^{2025}$, $i^{40}$, $i^{27}$, $i^{34}$
Voir la solution

1. Formes algébriques :

a) $z_1 = i(1 - 4i) + 3(2 - i)$

$z_1 = i - 4i^2 + 6 - 3i$

$z_1 = i + 4 + 6 - 3i = 10 - 2i$

$\boxed{z_1 = 10 - 2i}$

b) $z_2 = (3 - i)^2 + 6i$

$z_2 = 9 - 6i + i^2 + 6i$

$z_2 = 9 - 1 + (-6i + 6i) = 8$

$\boxed{z_2 = 8}$ (réel)

c) $z_3 = \dfrac{3}{1 - i}$

$z_3 = \dfrac{3(1 + i)}{(1 - i)(1 + i)} = \dfrac{3 + 3i}{2}$

$\boxed{z_3 = \dfrac{3}{2} + \dfrac{3}{2}i}$

d) $z_4 = \dfrac{1 + 2i}{2 - i}$

$z_4 = \dfrac{(1 + 2i)(2 + i)}{(2 - i)(2 + i)} = \dfrac{2 + i + 4i + 2i^2}{5}$

$z_4 = \dfrac{2 + 5i - 2}{5} = \dfrac{5i}{5} = i$

$\boxed{z_4 = i}$ (imaginaire pur)

e) $z_5 = (2 + i\sqrt{3})(\sqrt{3} - i)$

$z_5 = 2\sqrt{3} - 2i + i\sqrt{3}\sqrt{3} - i^2\sqrt{3}$

$z_5 = 2\sqrt{3} - 2i + 3i + \sqrt{3} = 3\sqrt{3} + i$

$\boxed{z_5 = 3\sqrt{3} + i}$

f) $z_6 = (2 + 5i)^2$

$z_6 = 4 + 20i + 25i^2 = 4 + 20i - 25$

$\boxed{z_6 = -21 + 20i}$

g) $z_7 = \dfrac{3 - 3i}{1 + i}$

$z_7 = \dfrac{3(1 - i)}{1 + i} = \dfrac{3(1 - i)^2}{(1 + i)(1 - i)}$

$z_7 = \dfrac{3(1 - 2i + i^2)}{2} = \dfrac{3(-2i)}{2} = -3i$

$\boxed{z_7 = -3i}$ (imaginaire pur)

2. Calcul de $i^n$ :

$i^{2025} = i^{4 \times 506 + 1} = (i^4)^{506} \times i = 1^{506} \times i = i$

$i^{40} = i^{4 \times 10} = (i^4)^{10} = 1$

$i^{27} = i^{4 \times 6 + 3} = (i^4)^6 \times i^3 = -i$

$i^{34} = i^{4 \times 8 + 2} = (i^4)^8 \times i^2 = -1$

$\boxed{i^{2025} = i,\; i^{40} = 1,\; i^{27} = -i,\; i^{34} = -1}$

Exercice 2
Conjugué
  1. Déterminer le conjugué des nombres complexes suivants :
    1. $z_1 = 3i$
    2. $z_2 = -i(1 + 4i)$
    1. $z_3 = (3 - 5i)^3$
    2. $z_4 = \dfrac{2i}{i + 3} - \dfrac{3}{2 + i}$
  2. Soit $z_5 = \dfrac{2 - i}{1 + i}$ et $z_6 = \dfrac{2 + i}{1 - i}$.
    Montrer que $\overline{z_6} = z_5$. Que peut-on en déduire sans calcul de $z_5 + z_6$ et $z_5 - z_6$ ?
Voir la solution

1. Conjugués :

a) $\overline{z_1} = \overline{3i} = -3i$

b) $z_2 = -i(1 + 4i) = -i - 4i^2 = -i + 4 = 4 - i$
$\overline{z_2} = \overline{4 - i} = 4 + i$

c) $\overline{z_3} = \overline{(3 - 5i)^3} = (3 + 5i)^3$ (car $\overline{z^n} = \bar{z}^n$)

d) $z_4 = \dfrac{2i}{i + 3} - \dfrac{3}{2 + i}$
$\overline{z_4} = \overline{\dfrac{2i}{i + 3}} - \overline{\dfrac{3}{2 + i}} = \dfrac{-2i}{-i + 3} - \dfrac{3}{2 - i} = \dfrac{-2i}{3 - i} - \dfrac{3}{2 - i}$

2. $\overline{z_6} = \overline{\dfrac{2 + i}{1 - i}} = \dfrac{2 - i}{1 + i} = z_5$

On en déduit que $z_5$ et $z_6$ sont conjugués.

Donc $z_5 + z_6$ est un réel et $z_5 - z_6$ est un imaginaire pur.

Exercice 3
Module et argument

Déterminer le module et un argument des nombres complexes suivants :

  1. $z_1 = -\sqrt{3} + i$
  2. $z_2 = -1 + i\sqrt{3}$
  3. $z_3 = 1 - i$
  4. $z_4 = 1 + i$
  1. $z_5 = -\sqrt{3} + i$
  2. $z_6 = \dfrac{2i - 2\sqrt{3}}{4i + 4}$
  3. $z_7 = (\sqrt{3} + i)(1 - i)^2$
  4. $z_8 = \dfrac{(-\sqrt{3} + i)^3}{(1 + i)^2}$
  1. $z_9 = 2 \dfrac{(\sqrt{3} + i)^2}{(-1 - i)^2}$
  2. $z_{10} = -2i (1 + i\sqrt{3})^6$
Voir la solution

Rappel : Pour $z = a + ib$, $|z| = \sqrt{a^2 + b^2}$ et $\arg(z) = \theta$ tel que $\cos\theta = \dfrac{a}{|z|}$ et $\sin\theta = \dfrac{b}{|z|}$.

a) $z_1 = -\sqrt{3} + i$

$|z_1| = \sqrt{3 + 1} = 2$

$\arg(z_1) = \dfrac{5\pi}{6}$

$\boxed{|z_1| = 2,\; \arg(z_1) = \frac{5\pi}{6}}$

b) $z_2 = -1 + i\sqrt{3}$

$|z_2| = \sqrt{1 + 3} = 2$

$\arg(z_2) = \dfrac{2\pi}{3}$

$\boxed{|z_2| = 2,\; \arg(z_2) = \frac{2\pi}{3}}$

c) $z_3 = 1 - i$

$|z_3| = \sqrt{1 + 1} = \sqrt{2}$

$\arg(z_3) = -\dfrac{\pi}{4}$

$\boxed{|z_3| = \sqrt{2},\; \arg(z_3) = -\frac{\pi}{4}}$

d) $z_4 = 1 + i$

$|z_4| = \sqrt{2}$

$\arg(z_4) = \dfrac{\pi}{4}$

$\boxed{|z_4| = \sqrt{2},\; \arg(z_4) = \frac{\pi}{4}}$

e) $z_5 = -\sqrt{3} + i$ (identique à a)

f) $z_6 = \dfrac{2i - 2\sqrt{3}}{4i + 4} = \dfrac{2(i - \sqrt{3})}{4(i + 1)} = \dfrac{i - \sqrt{3}}{2(i + 1)}$

Après calcul : $z_6 = \dfrac{1 - i\sqrt{3}}{2}$

$|z_6| = 1$, $\arg(z_6) = -\dfrac{\pi}{3}$

g) $z_7 = (\sqrt{3} + i)(1 - i)^2$

$(1 - i)^2 = -2i$

$z_7 = (\sqrt{3} + i)(-2i) = -2i\sqrt{3} - 2i^2 = 2 - 2i\sqrt{3}$

$|z_7| = 4$, $\arg(z_7) = -\dfrac{\pi}{3}$

h) $z_8 = \dfrac{(-\sqrt{3} + i)^3}{(1 + i)^2}$

$|z_8| = \dfrac{|-\sqrt{3} + i|^3}{|1 + i|^2} = \dfrac{2^3}{(\sqrt{2})^2} = \dfrac{8}{2} = 4$

$\arg(z_8) = 3 \times \dfrac{5\pi}{6} - 2 \times \dfrac{\pi}{4} = \dfrac{5\pi}{2} - \dfrac{\pi}{2} = 2\pi \equiv 0$

$\boxed{|z_8| = 4,\; \arg(z_8) = 0}$

i) $z_9 = 2\dfrac{(\sqrt{3} + i)^2}{(-1 - i)^2}$

$|z_9| = 2 \times \dfrac{2^2}{(\sqrt{2})^2} = 2 \times \dfrac{4}{2} = 4$

$\arg(z_9) = 2 \times \dfrac{\pi}{6} - 2 \times \left(-\dfrac{3\pi}{4}\right) = \dfrac{\pi}{3} + \dfrac{3\pi}{2} = \dfrac{11\pi}{6}$

j) $z_{10} = -2i(1 + i\sqrt{3})^6$

$|z_{10}| = 2 \times 2^6 = 128$

$\arg(z_{10}) = -\dfrac{\pi}{2} + 6 \times \dfrac{\pi}{3} = -\dfrac{\pi}{2} + 2\pi = \dfrac{3\pi}{2}$

Exercice 4
Forme trigonométrique

Soit les nombres complexes $z_1 = 1 + i\sqrt{3}$ et $z_2 = 1 - i$.

  1. Déterminer les formes trigonométriques de $z_1$, $z_2$ et $Z = \dfrac{z_1}{z_2}$.
  2. Déterminer la forme algébrique de $Z$.
  3. En déduire $\cos\left(\dfrac{7\pi}{12}\right)$ et $\sin\left(\dfrac{7\pi}{12}\right)$.
Voir la solution

1. Formes trigonométriques :

$z_1 = 1 + i\sqrt{3} = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$

$z_2 = 1 - i = \sqrt{2}\left(\cos\left(-\dfrac{\pi}{4}\right) + i\sin\left(-\dfrac{\pi}{4}\right)\right)$

$Z = \dfrac{z_1}{z_2} = \dfrac{2}{\sqrt{2}}\left[\cos\left(\dfrac{\pi}{3} + \dfrac{\pi}{4}\right) + i\sin\left(\dfrac{\pi}{3} + \dfrac{\pi}{4}\right)\right]$

$Z = \sqrt{2}\left[\cos\left(\dfrac{7\pi}{12}\right) + i\sin\left(\dfrac{7\pi}{12}\right)\right]$

2. Forme algébrique de $Z$ :

$Z = \dfrac{1 + i\sqrt{3}}{1 - i} = \dfrac{(1 + i\sqrt{3})(1 + i)}{(1 - i)(1 + i)} = \dfrac{1 + i + i\sqrt{3} + i^2\sqrt{3}}{2}$

$Z = \dfrac{1 - \sqrt{3}}{2} + \dfrac{1 + \sqrt{3}}{2}i$

3. Déduction :

$\cos\left(\dfrac{7\pi}{12}\right) = \dfrac{1 - \sqrt{3}}{2\sqrt{2}} = \dfrac{\sqrt{2} - \sqrt{6}}{4}$

$\sin\left(\dfrac{7\pi}{12}\right) = \dfrac{1 + \sqrt{3}}{2\sqrt{2}} = \dfrac{\sqrt{2} + \sqrt{6}}{4}$

Exercice 5
Formes trigonométrique et exponentielle

Dans chacun des cas suivants, déterminer la forme trigonométrique et la forme exponentielle.

  1. $z_1 = 4$
  2. $z_2 = -6$
  3. $z_3 = -i$
  4. $z_4 = -5 + 5i\sqrt{3}$
  1. $z_5 = -1 - i$
  2. $z_6 = \sqrt{3} - i$
  3. $z_{10} = -2e^{i\frac{\pi}{2}}$
  4. $z_{11} = ie^{i\frac{\pi}{3}}$
  1. $z_7 = -2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)$
  2. $z_9 = 4\left(\cos\dfrac{\pi}{12} + i\sin\dfrac{\pi}{12}\right)$
Voir la solution

a) $z_1 = 4 = 4(\cos 0 + i\sin 0) = 4e^{i0}$

b) $z_2 = -6 = 6(\cos\pi + i\sin\pi) = 6e^{i\pi}$

c) $z_3 = -i = \cos\left(-\dfrac{\pi}{2}\right) + i\sin\left(-\dfrac{\pi}{2}\right) = e^{-i\frac{\pi}{2}}$

d) $z_4 = -5 + 5i\sqrt{3} = 10\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right) = 10e^{i\frac{2\pi}{3}}$

e) $z_5 = -1 - i = \sqrt{2}\left(\cos\left(-\dfrac{3\pi}{4}\right) + i\sin\left(-\dfrac{3\pi}{4}\right)\right) = \sqrt{2}e^{-i\frac{3\pi}{4}}$

f) $z_6 = \sqrt{3} - i = 2\left(\cos\left(-\dfrac{\pi}{6}\right) + i\sin\left(-\dfrac{\pi}{6}\right)\right) = 2e^{-i\frac{\pi}{6}}$

g) $z_{10} = -2e^{i\frac{\pi}{2}} = 2e^{i\left(\frac{\pi}{2} + \pi\right)} = 2e^{i\frac{3\pi}{2}}$

h) $z_{11} = ie^{i\frac{\pi}{3}} = e^{i\frac{\pi}{2}} \times e^{i\frac{\pi}{3}} = e^{i\frac{5\pi}{6}}$

i) $z_7 = -2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right) = 2e^{i\left(\frac{\pi}{6} + \pi\right)} = 2e^{i\frac{7\pi}{6}}$

j) $z_9 = 4\left(\cos\dfrac{\pi}{12} + i\sin\dfrac{\pi}{12}\right) = 4e^{i\frac{\pi}{12}}$

Exercice 6
Forme trigonométrique

On considère les nombres complexes :

$z_1 = \dfrac{\sqrt{6} - i\sqrt{2}}{2}, \quad z_2 = 1 - i \quad \text{et} \quad z_3 = \dfrac{z_1}{z_2}$.

  1. Donner une écriture trigonométrique des nombres complexes $z_1$, $z_2$ et $z_3$.
  2. Écrire sous forme algébrique $z_3$.
    En déduire les valeurs exactes de $\cos\dfrac{\pi}{12}$ et $\sin\dfrac{\pi}{12}$.
Voir la solution

1. Formes trigonométriques :

$z_1 = \dfrac{\sqrt{6} - i\sqrt{2}}{2} = \sqrt{2}\left(\cos\dfrac{\pi}{12} - i\sin\dfrac{\pi}{12}\right) = \sqrt{2}e^{-i\frac{\pi}{12}}$

$z_2 = 1 - i = \sqrt{2}\left(\cos\left(-\dfrac{\pi}{4}\right) + i\sin\left(-\dfrac{\pi}{4}\right)\right) = \sqrt{2}e^{-i\frac{\pi}{4}}$

$z_3 = \dfrac{z_1}{z_2} = e^{i\left(-\frac{\pi}{12} + \frac{\pi}{4}\right)} = e^{i\frac{\pi}{6}}$

2. Forme algébrique de $z_3$ :

$z_3 = \dfrac{\sqrt{6} - i\sqrt{2}}{2(1 - i)} = \dfrac{\sqrt{6} - i\sqrt{2}}{2(1 - i)} \times \dfrac{1 + i}{1 + i} = \dfrac{\sqrt{6} + i\sqrt{6} - i\sqrt{2} + \sqrt{2}}{4}$

$z_3 = \dfrac{\sqrt{6} + \sqrt{2}}{4} + i\dfrac{\sqrt{6} - \sqrt{2}}{4} = \cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}$

Donc :

$\cos\dfrac{\pi}{12} = \dfrac{\sqrt{6} + \sqrt{2}}{4}$ et $\sin\dfrac{\pi}{12} = \dfrac{\sqrt{6} - \sqrt{2}}{4}$

Exercice 7
Classique !
  1. Écrire $1 + i$ sous forme trigonométrique. En déduire l'expression de $(1 + i)^6$ par la formule de Moivre.
  2. Calculer $\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right)^{2026}$.
Voir la solution

1. $1 + i = \sqrt{2}e^{i\frac{\pi}{4}}$

$(1 + i)^6 = (\sqrt{2})^6 \times e^{i\frac{6\pi}{4}} = 2^3 \times e^{i\frac{3\pi}{2}} = 8 \times (-i) = -8i$

2. $-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2} = e^{i\frac{2\pi}{3}}$

$\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right)^{2026} = \left(e^{i\frac{2\pi}{3}}\right)^{2026} = e^{i\frac{4052\pi}{3}}$

$2026 \equiv 1 \pmod{6}$ donc :

$\boxed{\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right)^{2026} = e^{i\frac{2\pi}{3}} = -\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}}$

Exercice 8
Racines carrées et Équations
  1. Déterminer les racines carrées de :
    1. $z = 3 + 4i$
    2. $z = 8 - 6i$
    1. $z = -5 + 12i$
    2. $z = 7 + 24i$
  2. Résoudre dans $\mathbb{C}$ les équations suivantes :
    1. $4z^2 - 12z + 153 = 0$
    2. $z^2 - 4z + 5 = 0$
    3. $z^2 + z + 1 = 0$
    4. $iz^2 - iz - 3 - i = 0$
    1. $iz^2 + (1 - 5i)z + 6i - 2 = 0$
    2. $z^2 - (2 + 4i)z - 2 + 4i = 0$
    3. $(3 + i)z^2 - (7 - i)z + 10 = 0$
    4. $z^2 - (1 + i\sqrt{3})z - 1 + i\sqrt{3} = 0$
Voir la solution

1. Racines carrées :

Pour $z = a + ib$, les racines carrées sont $\pm(\alpha + i\beta)$ avec :

$\alpha = \sqrt{\dfrac{|z| + a}{2}}$, $\beta = \text{signe}(b)\sqrt{\dfrac{|z| - a}{2}}$

a) $z = 3 + 4i$, $|z| = 5$
$\alpha = \sqrt{\dfrac{5 + 3}{2}} = 2$, $\beta = \sqrt{\dfrac{5 - 3}{2}} = 1$
$\boxed{\text{Racines : } \pm(2 + i)}$

b) $z = 8 - 6i$, $|z| = 10$
$\alpha = \sqrt{\dfrac{10 + 8}{2}} = 3$, $\beta = -\sqrt{\dfrac{10 - 8}{2}} = -1$
$\boxed{\text{Racines : } \pm(3 - i)}$

c) $z = -5 + 12i$, $|z| = 13$
$\alpha = \sqrt{\dfrac{13 - 5}{2}} = 2$, $\beta = \sqrt{\dfrac{13 + 5}{2}} = 3$
$\boxed{\text{Racines : } \pm(2 + 3i)}$

d) $z = 7 + 24i$, $|z| = 25$
$\alpha = \sqrt{\dfrac{25 + 7}{2}} = 4$, $\beta = \sqrt{\dfrac{25 - 7}{2}} = 3$
$\boxed{\text{Racines : } \pm(4 + 3i)}$

2. Équations :

a) $4z^2 - 12z + 153 = 0$
$\Delta = 144 - 4(4)(153) = 144 - 2448 = -2304 = (48i)^2$
$z = \dfrac{12 \pm 48i}{8} = \dfrac{3}{2} \pm 6i$

b) $z^2 - 4z + 5 = 0$
$\Delta = 16 - 20 = -4 = (2i)^2$
$z = \dfrac{4 \pm 2i}{2} = 2 \pm i$

c) $z^2 + z + 1 = 0$
$\Delta = 1 - 4 = -3 = (i\sqrt{3})^2$
$z = \dfrac{-1 \pm i\sqrt{3}}{2} = e^{\pm i\frac{2\pi}{3}}$

d) $iz^2 - iz - 3 - i = 0$
$\Delta = (-i)^2 - 4i(-3 - i) = -1 + 12i + 4i^2 = -5 + 12i$
Les racines carrées de $-5 + 12i$ sont $\pm(2 + 3i)$
$z = \dfrac{i \pm (2 + 3i)}{2i}$
$z_1 = \dfrac{2 + 4i}{2i} = 2 - i$, $z_2 = \dfrac{-2 - 2i}{2i} = -1 + i$

Exercice 9
Racines $n$-ièmes
  1. Résoudre dans $\mathbb{C} : z^6 = 4\sqrt{2}(-1 + i)$
    1. Résoudre dans $\mathbb{C} : z^3 = 1$.
    2. Calculer $(1 + i)^3$.
    3. En déduire les racines cubiques de $z = -2 + 2i$.
  3. Résoudre dans $\mathbb{C} : z^3 = 4\sqrt{2}(-1 + i)$
Voir la solution

1. $4\sqrt{2}(-1 + i) = 4\sqrt{2} \times \sqrt{2} e^{i\frac{3\pi}{4}} = 8e^{i\frac{3\pi}{4}}$

$z^6 = 8e^{i\frac{3\pi}{4}} \implies z = 8^{1/6} e^{i\left(\frac{3\pi}{24} + \frac{2k\pi}{6}\right)} = \sqrt{2}e^{i\left(\frac{\pi}{8} + \frac{k\pi}{3}\right)}$, $k = 0,1,2,3,4,5$

2.a) $z^3 = 1 = e^{i0} \implies z = e^{i\frac{2k\pi}{3}}$, $k = 0,1,2$

$\boxed{z_0 = 1,\; z_1 = -\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2},\; z_2 = -\dfrac{1}{2} - i\dfrac{\sqrt{3}}{2}}$

2.b) $(1 + i)^3 = (1 + i)^2(1 + i) = 2i(1 + i) = 2i - 2 = -2 + 2i$

2.c) Les racines cubiques de $-2 + 2i$ sont :
$z_k = (1 + i) \times e^{i\frac{2k\pi}{3}}$, $k = 0,1,2$

3. $4\sqrt{2}(-1 + i) = 8e^{i\frac{3\pi}{4}}$
$z^3 = 8e^{i\frac{3\pi}{4}} \implies z = 2e^{i\left(\frac{\pi}{4} + \frac{2k\pi}{3}\right)}$, $k = 0,1,2$

Exercice 10
Racines $n$-ièmes

On donne $z_0 = 1 - i\sqrt{3}$

  1. Donner une écriture trigonométrique de $z_0$.
  2. Montrer que $z_0^4 = -8 + 8i\sqrt{3}$.
  3. Résoudre dans $\mathbb{C}$ l'équation $z^4 = 1$.
  4. En déduire les solutions de $(E) : z^4 = -8 + 8i\sqrt{3}$ sous forme algébrique et sous forme trigonométrique.
Voir la solution

1. $z_0 = 1 - i\sqrt{3} = 2e^{-i\frac{\pi}{3}}$

2. $z_0^4 = (2e^{-i\frac{\pi}{3}})^4 = 16e^{-i\frac{4\pi}{3}} = 16\left(\cos\dfrac{4\pi}{3} - i\sin\dfrac{4\pi}{3}\right) = 16\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right) = -8 + 8i\sqrt{3}$

3. $z^4 = 1 \implies z = e^{i\frac{2k\pi}{4}} = e^{i\frac{k\pi}{2}}$, $k = 0,1,2,3$
$\boxed{z_0 = 1,\; z_1 = i,\; z_2 = -1,\; z_3 = -i}$

4. Les solutions de $z^4 = -8 + 8i\sqrt{3} = z_0^4$ sont :
$z = z_0 \times e^{i\frac{k\pi}{2}}$, $k = 0,1,2,3$
$z_k = 2e^{i\left(-\frac{\pi}{3} + \frac{k\pi}{2}\right)}$, $k = 0,1,2,3$

Forme algébrique :
$z_0 = 2e^{-i\frac{\pi}{3}} = 1 - i\sqrt{3}$
$z_1 = 2e^{i\frac{\pi}{6}} = \sqrt{3} + i$
$z_2 = 2e^{i\frac{2\pi}{3}} = -1 + i\sqrt{3}$
$z_3 = 2e^{i\frac{7\pi}{6}} = -\sqrt{3} - i$

Exercice 11
Linéarisation
  1. Linéariser les polynômes trigonométriques suivants :
    1. $h(x) = \cos x \sin^2 x$
    2. $k(x) = \cos 2x \sin 3x$
    3. $m(x) = \sin^3 x$
    1. Linéariser $f(x) = \sin^4 x + \cos^4 x$.
    2. Déduisez-en une primitive sur $\mathbb{R}$ de $f$.
Voir la solution

1.a) $h(x) = \cos x \sin^2 x = \cos x \times \dfrac{1 - \cos 2x}{2} = \dfrac{1}{2}\cos x - \dfrac{1}{2}\cos x \cos 2x$

$h(x) = \dfrac{1}{2}\cos x - \dfrac{1}{4}(\cos 3x + \cos x) = \dfrac{1}{4}\cos x - \dfrac{1}{4}\cos 3x$

1.b) $k(x) = \cos 2x \sin 3x = \dfrac{1}{2}[\sin(3x + 2x) + \sin(3x - 2x)] = \dfrac{1}{2}(\sin 5x + \sin x)$

1.c) $m(x) = \sin^3 x = \dfrac{3\sin x - \sin 3x}{4}$

2.a) $\sin^4 x = \dfrac{\cos 4x - 4\cos 2x + 3}{8}$
$\cos^4 x = \dfrac{\cos 4x + 4\cos 2x + 3}{8}$
$f(x) = \sin^4 x + \cos^4 x = \dfrac{2\cos 4x + 6}{8} = \dfrac{1}{4}\cos 4x + \dfrac{3}{4}$

2.b) $F(x) = \dfrac{1}{16}\sin 4x + \dfrac{3}{4}x + C$

Exercice 12
Lieux géométriques

Dans chacun des cas, déterminer géométriquement l'ensemble des points $M$ d'affixe $z$ vérifiant la relation donnée.

  1. $|z + 1 + 4i| = |z - 1 + i|$
  2. $|z + 1 + 4i| = 4$
  3. $|\overline{z} + 1 - 4i| = |z - 2i|$
  4. $|3iz + 6| = 3|z - 1 + i|$
  5. $\arg\dfrac{z - 2i}{z - 1 + i} = \dfrac{\pi}{2}[\pi]$
Voir la solution

1. $|z + 1 + 4i| = |z - 1 + i|$
$|z - (-1 - 4i)| = |z - (1 - i)|$
Ensemble des points équidistants de $A(-1, -4)$ et $B(1, -1)$.
$\boxed{\text{Médiatrice du segment }[AB]}$

2. $|z + 1 + 4i| = 4$
$|z - (-1 - 4i)| = 4$
$\boxed{\text{Cercle de centre }A(-1, -4)\text{ et de rayon }4}$

3. $|\overline{z} + 1 - 4i| = |z - 2i|$
$|\overline{z} - (-1 + 4i)| = |z - 2i|$
$|z - (-1 - 4i)| = |z - 2i|$
$\boxed{\text{Médiatrice du segment joignant }A(-1, -4)\text{ et }B(0, 2)}$

4. $|3iz + 6| = 3|z - 1 + i|$
$|3i(z - 2i)| = 3|z - (1 - i)|$
$3|z - 2i| = 3|z - (1 - i)|$
$|z - 2i| = |z - (1 - i)|$
$\boxed{\text{Médiatrice du segment joignant }A(0, 2)\text{ et }B(1, -1)}$

5. $\arg\dfrac{z - 2i}{z - 1 + i} = \dfrac{\pi}{2}[\pi]$
$\arg(z - 2i) - \arg(z - 1 + i) = \dfrac{\pi}{2}[\pi]$
$\boxed{\text{Cercle de diamètre }[AB]\text{ où }A(0, 2)\text{ et }B(1, -1)\text{ privé de }A\text{ et }B}$

Exercice 13
Lieux géométriques

On considère l'expression $Z = \dfrac{z + 1}{z - 2i}$ où $z \neq 2i$. Déterminer par la méthode géométrique, l'ensemble des points $M(z)$ tels que :

  1. $Z$ soit réel.
  2. $Z$ soit imaginaire pur.
  3. $\arg(Z) = \dfrac{\pi}{2}[2\pi]$.
Voir la solution

$Z = \dfrac{z + 1}{z - 2i} = \dfrac{z - (-1)}{z - 2i}$

1. $Z \in \mathbb{R} \iff \arg(Z) = 0[\pi]$
$\arg(z + 1) - \arg(z - 2i) = 0[\pi]$
$(\overrightarrow{MA}, \overrightarrow{MB}) = 0[\pi]$
$\boxed{\text{Droite }(AB)\text{ privée de }B}$ où $A(-1, 0)$ et $B(0, 2)$

2. $Z$ imaginaire pur $\iff \arg(Z) = \dfrac{\pi}{2}[\pi]$
$\boxed{\text{Cercle de diamètre }[AB]\text{ privé de }A\text{ et }B}$

3. $\arg(Z) = \dfrac{\pi}{2}[2\pi]$
$\boxed{\text{Demi-cercle de diamètre }[AB]\text{ privé de }A\text{ et }B}$
