Exercice 2
Équations et inéquations dans $\mathbb{R}$
1. Résoudre dans $\mathbb{R}$ les équations :
  1. $e^{2x} - 3e^x + 2 = 0$
  2. $e^x - 2e^{-x} - 1 = 0$
  3. $e^{3x-1} = 1$
  4. $e^{x^2 - 4} = e^{3x}$
  5. $\dfrac{e^x + 3}{e^x - 1} = 2$
  6. $e^{2x} + e^x - 6 = 0$
2. Résoudre dans $\mathbb{R}$ les inéquations :
  1. $e^{2x} - 4 > 0$
  2. $e^x + 1 - 2e^{-x} \le 0$
  3. $e^{x^2 - 1} < e^{x+1}$
  4. $\dfrac{e^x - 1}{e^x + 2} \ge 0$
  5. $e^{3x} - 2e^{2x} - e^x + 2 > 0$
  6. $\dfrac{2}{e^x - 1} < 1$
Voir les solutions

1. Équations :

1. $e^{2x} - 3e^x + 2 = 0$

Posons $X = e^x > 0$. $X^2 - 3X + 2 = 0 \iff (X-1)(X-2) = 0$

$X = 1 \iff e^x = 1 \iff x = 0$

$X = 2 \iff e^x = 2 \iff x = \ln 2$

$\boxed{S = \{0, \ln 2\}}$

2. $e^x - 2e^{-x} - 1 = 0$

Multiplions par $e^x$ : $e^{2x} - e^x - 2 = 0$

$X = e^x > 0$, $X^2 - X - 2 = 0 \iff (X-2)(X+1) = 0$

$X = 2$ (car $X > 0$) $\iff x = \ln 2$

$\boxed{S = \{\ln 2\}}$

3. $e^{3x-1} = 1 \iff 3x-1 = 0 \iff x = \dfrac{1}{3}$

$\boxed{S = \left\{\dfrac{1}{3}\right\}}$

4. $e^{x^2 - 4} = e^{3x} \iff x^2 - 4 = 3x \iff x^2 - 3x - 4 = 0$

$(x-4)(x+1) = 0 \iff x = 4$ ou $x = -1$

$\boxed{S = \{-1, 4\}}$

5. $\dfrac{e^x + 3}{e^x - 1} = 2$, $e^x \neq 1$

$e^x + 3 = 2e^x - 2 \iff e^x = 5 \iff x = \ln 5$

$\boxed{S = \{\ln 5\}}$

6. $e^{2x} + e^x - 6 = 0$

$X = e^x > 0$, $X^2 + X - 6 = 0 \iff (X+3)(X-2) = 0$

$X = 2 \iff x = \ln 2$

$\boxed{S = \{\ln 2\}}$

2. Inéquations :

1. $e^{2x} - 4 > 0 \iff e^{2x} > 4 \iff 2x > \ln 4 \iff x > \ln 2$

$\boxed{S = ]\ln 2; +\infty[}$

2. $e^x + 1 - 2e^{-x} \le 0$

Multiplions par $e^x > 0$ : $e^{2x} + e^x - 2 \le 0$

$X = e^x > 0$, $X^2 + X - 2 \le 0 \iff (X+2)(X-1) \le 0$

$-2 \le X \le 1$ et $X > 0 \implies 0 < X \le 1$

$X \le 1 \iff e^x \le 1 \iff x \le 0$

$\boxed{S = ]-\infty; 0]}$

3. $e^{x^2 - 1} < e^{x+1} \iff x^2 - 1 < x + 1 \iff x^2 - x - 2 < 0$

$(x-2)(x+1) < 0 \iff -1 < x < 2$

$\boxed{S = ]-1; 2[}$

4. $\dfrac{e^x - 1}{e^x + 2} \ge 0$

$e^x + 2 > 0$ pour tout $x$, donc le signe est celui de $e^x - 1$

$e^x - 1 \ge 0 \iff e^x \ge 1 \iff x \ge 0$

$\boxed{S = [0; +\infty[}$

5. $e^{3x} - 2e^{2x} - e^x + 2 > 0$

$(e^x - 2)(e^x - 1)(e^x + 1) > 0$

$e^x + 1 > 0$ donc signe de $(e^x - 2)(e^x - 1)$

$x < 0$ ou $x > \ln 2$

$\boxed{S = ]-\infty; 0[ \cup ]\ln 2; +\infty[}$

6. $\dfrac{2}{e^x - 1} < 1$

$\dfrac{2}{e^x - 1} - 1 < 0 \iff \dfrac{2 - (e^x - 1)}{e^x - 1} < 0 \iff \dfrac{3 - e^x}{e^x - 1} < 0$

Étudions le signe : $e^x - 1 = 0 \iff x = 0$ ; $3 - e^x = 0 \iff x = \ln 3$

Tableau des signes :

$x < 0$ : $e^x - 1 < 0$, $3 - e^x > 0$ $\implies$ quotient $< 0$

$0 < x < \ln 3$ : $e^x - 1 > 0$, $3 - e^x > 0$ $\implies$ quotient $> 0$

$x > \ln 3$ : $e^x - 1 > 0$, $3 - e^x < 0$ $\implies$ quotient $< 0$

$\boxed{S = ]-\infty; 0[ \cup ]\ln 3; +\infty[}$

Exercice 3
Étude de fonctions comportant la fonction exponentielle

1. Soit $f$ la fonction définie sur $\mathbb{R}$ par : $f(x) = (x-1)e^x + 1$.

  1. Étudier les limites de $f$ en $-\infty$ et $+\infty$.
  2. Étudier les variations de $f$ et dresser son tableau de variation.
  3. Déduire le signe de $f(x)$ sur $\mathbb{R}$.

2. Soit $g$ la fonction définie par : $g(x) = \dfrac{e^x - 1}{e^x + 1}$.

  1. Déterminer l'ensemble de définition $D_g$ de $g$.
  2. Montrer que $g$ est une fonction impaire.
  3. Calculer la limite de $g$ en $+\infty$ et interpréter géométriquement le résultat.
  4. Calculer $g'(x)$ et dresser le tableau de variation de $g$.
  5. Déterminer l'équation de la tangente $(T)$ à la courbe de $g$ au point d'abscisse $0$.
Voir les solutions

1.a) Limites :

$\lim\limits_{x \to +\infty} f(x) = \lim\limits_{x \to +\infty} (x-1)e^x + 1 = +\infty$ (car $e^x$ l'emporte)

$\lim\limits_{x \to -\infty} f(x) = \lim\limits_{x \to -\infty} (x-1)e^x + 1 = 0 + 1 = 1$

1.b) Variations :

$f'(x) = e^x + (x-1)e^x = x e^x$

$f'(x) = 0 \iff x = 0$

$f'(x) < 0$ sur $]-\infty; 0[$ et $f'(x) > 0$ sur $]0; +\infty[$

$f$ est décroissante sur $]-\infty; 0]$ et croissante sur $[0; +\infty[$

$f(0) = (0-1)e^0 + 1 = 0$

Donc $f(x) \ge 0$ pour tout $x \in \mathbb{R}$.

2.a) $D_g = \mathbb{R}$ car $e^x + 1 > 0$ pour tout $x$.

2.b) $g(-x) = \dfrac{e^{-x} - 1}{e^{-x} + 1} = \dfrac{1 - e^x}{1 + e^x} = -\dfrac{e^x - 1}{e^x + 1} = -g(x)$

Donc $g$ est impaire.

2.c) $\lim\limits_{x \to +\infty} g(x) = \lim\limits_{x \to +\infty} \dfrac{e^x}{e^x} = 1$

$y = 1$ est asymptote horizontale en $+\infty$.

Par imparité, $\lim\limits_{x \to -\infty} g(x) = -1$, $y = -1$ est asymptote horizontale en $-\infty$.

2.d) $g'(x) = \dfrac{e^x(e^x+1) - (e^x-1)e^x}{(e^x+1)^2} = \dfrac{2e^x}{(e^x+1)^2} > 0$

$g$ est strictement croissante sur $\mathbb{R}$.

2.e) $g(0) = \dfrac{1-1}{1+1} = 0$

$g'(0) = \dfrac{2}{4} = \dfrac{1}{2}$

$(T) : y = g'(0)(x-0) + g(0) = \dfrac{1}{2}x$

$\boxed{(T) : y = \dfrac{x}{2}}$
