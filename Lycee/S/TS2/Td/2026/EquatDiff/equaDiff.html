I. Généralités et équations du premier ordre

Exercice 1

Montrer que chacune des fonctions $f$ est solution de l'équation différentielle $(E)$ associée :

  1. $f(x) = \cos(2x+3) \quad \text{pour } (E) : y'' = -4y$
  2. $f(x) = \sin(2x) \quad \text{pour } (E) : y'' + 3y = -2\sin x \cos x$
  3. $f(x) = x\mathrm{e}^{x} \quad \text{pour } (E) : y' - y = \mathrm{e}^{x}$
  4. $f(x) = \mathrm{e}^{x}\ln x \quad \text{pour } (E) : y'' - 2y' + y = -\dfrac{1}{x^{2}}\mathrm{e}^{x}$
Voir la solution

1. $f(x) = \cos(2x+3)$

$f'(x) = -2\sin(2x+3)$, $f''(x) = -4\cos(2x+3) = -4f(x)$

Donc $f'' = -4f \iff f'' + 4f = 0$

2. $f(x) = \sin(2x)$

$f''(x) = -4\sin(2x)$, $3f(x) = 3\sin(2x)$

$f'' + 3f = -4\sin(2x) + 3\sin(2x) = -\sin(2x) = -2\sin x \cos x$

3. $f(x) = xe^x$

$f'(x) = e^x + xe^x = (x+1)e^x$

$f' - f = (x+1)e^x - xe^x = e^x$

4. $f(x) = e^x\ln x$

$f'(x) = e^x\ln x + \frac{e^x}{x}$, $f''(x) = e^x\ln x + \frac{2e^x}{x} - \frac{e^x}{x^2}$

$f'' - 2f' + f = -\frac{e^x}{x^2}$

Exercice 2

Déterminer la solution $f$ de chacune des équations différentielles $(E)$ suivantes vérifiant la condition initiale $f(x_0) = y_0$ :

  1. $(E) : -3y' + 2y = 0 \quad \text{avec } x_0 = 3 \text{ et } y_0 = 1$
  2. $(E) : 3y' + 6y = 0 \quad \text{avec } x_0 = -4 \text{ et } y_0 = 2$
  3. $(E) : 5y' + y = 0 \quad \text{avec } x_0 = -5 \text{ et } y_0 = 1$
  4. $(E) : 2y - 5y' = 0 \quad \text{avec } x_0 = 1 \text{ et } y_0 = -3$
Voir la solution

1. $-3y' + 2y = 0 \iff y' = \frac{2}{3}y$

$y = Ce^{\frac{2}{3}x}$, $y(3) = 1 \implies Ce^2 = 1 \implies C = e^{-2}$

$\boxed{f(x) = e^{\frac{2}{3}x - 2}}$

2. $3y' + 6y = 0 \iff y' = -2y$

$y = Ce^{-2x}$, $y(-4) = 2 \implies Ce^8 = 2 \implies C = 2e^{-8}$

$\boxed{f(x) = 2e^{-2x-8}}$

3. $5y' + y = 0 \iff y' = -\frac{1}{5}y$

$y = Ce^{-\frac{x}{5}}$, $y(-5) = 1 \implies Ce^1 = 1 \implies C = e^{-1}$

$\boxed{f(x) = e^{-\frac{x}{5} - 1}}$

4. $2y - 5y' = 0 \iff y' = \frac{2}{5}y$

$y = Ce^{\frac{2}{5}x}$, $y(1) = -3 \implies Ce^{\frac{2}{5}} = -3 \implies C = -3e^{-\frac{2}{5}}$

$\boxed{f(x) = -3e^{\frac{2}{5}x - \frac{2}{5}}}$

II. Équations du second ordre sans second membre

Exercice 3

Déterminer la solution $f$ de chacune des équations différentielles $(E)$ suivantes vérifiant les conditions $f(x_0) = y_0$ et $f'(x_0) = y'_0$ :

1. $2y'' - 3y' - 2y = 0 \quad \text{avec } f(0) = 2 \text{ et } f'(0) = 3$
2. $y'' + y' + y = 0 \quad \text{avec } f(0) = 1 \text{ et } f'(0) = -1$
3. $4y'' - 4y' + y = 0 \quad \text{avec } f(0) = -3 \text{ et } f'(0) = 2$
4. $y'' - 5y' + 6y = 0 \quad \text{avec } f(0) = 0 \text{ et } f'(0) = 6$
5. $9y'' + 6y' + y = 0 \quad \text{avec } f(0) = 1 \text{ et } f'(0) = 2$
6. $y'' - 4y' + 5y = 0 \quad \text{avec } f(0) = -1 \text{ et } f'(0) = 3$
Voir la solution

1. $2r^2 - 3r - 2 = 0 \implies r = -\frac{1}{2}$ ou $r = 2$

$y = Ae^{-\frac{x}{2}} + Be^{2x}$

$y(0) = A + B = 2$, $y'(0) = -\frac{A}{2} + 2B = 3$

$\boxed{f(x) = \frac{2}{5}e^{-\frac{x}{2}} + \frac{8}{5}e^{2x}}$

2. $r^2 + r + 1 = 0 \implies \Delta = -3 \implies r = -\frac{1}{2} \pm i\frac{\sqrt{3}}{2}$

$y = e^{-\frac{x}{2}}(A\cos\frac{\sqrt{3}}{2}x + B\sin\frac{\sqrt{3}}{2}x)$

$\boxed{f(x) = e^{-\frac{x}{2}}(\cos\frac{\sqrt{3}}{2}x - \frac{\sqrt{3}}{3}\sin\frac{\sqrt{3}}{2}x)}$

3. $4r^2 - 4r + 1 = 0 \implies r = \frac{1}{2}$ (double)

$y = (Ax + B)e^{\frac{x}{2}}$, $y(0) = B = -3$, $y'(0) = \frac{B}{2} + A = 2 \implies A = \frac{7}{2}$

$\boxed{f(x) = (\frac{7}{2}x - 3)e^{\frac{x}{2}}}$

4. $r^2 - 5r + 6 = 0 \implies r = 2$ ou $r = 3$

$y = Ae^{2x} + Be^{3x}$, $y(0) = A + B = 0$, $y'(0) = 2A + 3B = 6$

$A = -6$, $B = 6$

$\boxed{f(x) = -6e^{2x} + 6e^{3x}}$

5. $9r^2 + 6r + 1 = 0 \implies r = -\frac{1}{3}$ (double)

$y = (Ax + B)e^{-\frac{x}{3}}$, $y(0) = B = 1$, $y'(0) = -\frac{B}{3} + A = 2 \implies A = \frac{7}{3}$

$\boxed{f(x) = (\frac{7}{3}x + 1)e^{-\frac{x}{3}}}$

6. $r^2 - 4r + 5 = 0 \implies \Delta = -4 \implies r = 2 \pm i$

$y = e^{2x}(A\cos x + B\sin x)$, $y(0) = A = -1$, $y'(0) = 2A + B = 3 \implies B = 5$

$\boxed{f(x) = e^{2x}(-\cos x + 5\sin x)}$

Exercice 4

Soit $(E)$ l'équation différentielle du second ordre : $y'' - 3y' + 2y = 0$.

  1. Quelles sont les solutions de $(E)$ ?
  2. Quelle est la solution de $(E)$ dont la courbe représentative $\mathcal{C}$ admet au point d'abscisse $x=0$ la même tangente que la courbe $\mathcal{C'}$ d'équation $y=x$ ?
  3. Préciser les positions relatives de $\mathcal{C}$ et $\mathcal{C'}$.
Voir la solution

a. $r^2 - 3r + 2 = 0 \implies r = 1$ ou $r = 2$

$\boxed{y = Ae^x + Be^{2x}}$

b. Tangente de $\mathcal{C'}$ en 0 : $y = x$ donc $y'(0) = 1$ et $y(0) = 0$

$y(0) = A + B = 0$, $y'(0) = A + 2B = 1 \implies A = -1$, $B = 1$

$\boxed{y = -e^x + e^{2x}}$

c. $y - x = e^{2x} - e^x - x$

Étudier le signe de $h(x) = e^{2x} - e^x - x$

Exercice 5
  1. Résoudre l'équation différentielle : $y'' + 16y = 0$.
  2. Trouver la solution $f$ de cette équation vérifiant : $f(0) = 1 \text{ et } f'(0) = 4$.
  3. Trouver deux réels positifs $\omega$ et $\varphi$ tels que pour tout réel $t$, $f(t) = \sqrt{2} \cos(\omega t - \varphi)$.
  4. Calculer la valeur moyenne de $f$ sur l'intervalle $\left[0\,;\ \dfrac{\pi}{8}\right]$.
Voir la solution

1. $r^2 + 16 = 0 \implies r = \pm 4i$

$\boxed{y = A\cos(4x) + B\sin(4x)}$

2. $f(0) = A = 1$, $f'(0) = 4B = 4 \implies B = 1$

$\boxed{f(x) = \cos(4x) + \sin(4x)}$

3. $f(x) = \sqrt{2}\cos(4x - \frac{\pi}{4})$

$\boxed{\omega = 4,\ \varphi = \frac{\pi}{4}}$

4. Valeur moyenne = $\frac{1}{\pi/8} \int_0^{\pi/8} f(x) dx = \frac{8}{\pi} \left[\frac{1}{4}\sin(4x) - \frac{1}{4}\cos(4x)\right]_0^{\pi/8}$

$= \frac{8}{\pi} \times \frac{1}{4}(\sin\frac{\pi}{2} - \cos\frac{\pi}{2} - \sin 0 + \cos 0) = \frac{2}{\pi}(1 - 0 - 0 + 1) = \frac{4}{\pi}$

$\boxed{\frac{4}{\pi}}$

III. Équations linéaires du second ordre avec second membre

Exercice 6

On considère l'équation $(E) : y'' + my' + py = g(x)$ où $m$ et $p$ sont deux réels et $g$ une fonction continue sur $\mathbb{R}$.

Partie A : Étude générale

On suppose qu'il existe une solution particulière $f_1$ de $(E)$.

  1. Prouver que si $f$ est solution de $(E)$, alors $f - f_1$ est solution de l'équation homogène associée : $(E_0) : y'' + my' + py = 0$.
  2. Prouver que si $h$ est solution de $(E_0)$, alors $h + f_1$ est solution de $(E)$.
  3. En déduire l'ensemble des solutions de $(E)$ dès qu'une solution particulière est connue.
Voir la solution

1. Si $f$ est solution de $(E)$ et $f_1$ est solution de $(E)$, alors :

$(f - f_1)'' + m(f - f_1)' + p(f - f_1) = (f'' + mf' + pf) - (f_1'' + mf_1' + pf_1) = g(x) - g(x) = 0$

Donc $f - f_1$ est solution de $(E_0)$.

2. Si $h$ est solution de $(E_0)$ et $f_1$ solution de $(E)$, alors :

$(h + f_1)'' + m(h + f_1)' + p(h + f_1) = 0 + g(x) = g(x)$

Donc $h + f_1$ est solution de $(E)$.

3. L'ensemble des solutions de $(E)$ est :

$\boxed{\{f_1 + h \mid h \text{ solution de } (E_0)\}}$

Exercice 6 (suite)
Partie B : Cas où $g$ est une fonction polynôme
  1. On considère l'équation $(E) : y'' - 3y' + 2y = x + 1$.
    1. Déterminer les réels $a$ et $b$ tels que $f_1 : x \mapsto ax + b$ soit solution de $(E)$.
    2. Résoudre $(E)$.
  2. On considère l'équation $(E) : y'' - 3y' + 2y = x^2 + 2x + 3$.
    1. Déterminer les réels $a, b$ et $c$ tels que $f_1 : x \mapsto ax^2 + bx + c$ soit solution de $(E)$.
    2. Résoudre $(E)$.
  3. Résoudre de manière analogue :
    1. $y'' - 8y' + 17y = x^2 - x + 2$
    2. $y'' + 4y' + 4y = x^2 + 1$
Voir la solution

1.a) $y = ax + b$, $y' = a$, $y'' = 0$

$0 - 3a + 2(ax + b) = x + 1 \implies (2a - 3a)x + (2b - 3a) = x + 1$

$\begin{cases} -a = 1 \\ 2b - 3a = 1 \end{cases} \implies a = -1,\ b = -1$

$\boxed{f_1(x) = -x - 1}$

1.b) $r^2 - 3r + 2 = 0 \implies r = 1$ ou $r = 2$

$\boxed{y = Ae^x + Be^{2x} - x - 1}$

2.a) $y = ax^2 + bx + c$, $y' = 2ax + b$, $y'' = 2a$

$2a - 3(2ax + b) + 2(ax^2 + bx + c) = 2ax^2 + (-6a + 2b)x + (2a - 3b + 2c) = x^2 + 2x + 3$

$\begin{cases} 2a = 1 \\ -6a + 2b = 2 \\ 2a - 3b + 2c = 3 \end{cases} \implies a = \frac{1}{2},\ b = \frac{5}{2},\ c = \frac{17}{4}$

2.b) $\boxed{y = Ae^x + Be^{2x} + \frac{1}{2}x^2 + \frac{5}{2}x + \frac{17}{4}}$

3.a) $r^2 - 8r + 17 = 0 \implies \Delta = -4 \implies r = 4 \pm i$

Solution particulière : $y = \frac{1}{17}x^2 + \frac{1}{17}x + \frac{31}{289}$

$\boxed{y = e^{4x}(A\cos x + B\sin x) + \frac{1}{17}x^2 + \frac{1}{17}x + \frac{31}{289}}$

3.b) $r^2 + 4r + 4 = 0 \implies r = -2$ (double)

Solution particulière : $y = \frac{1}{4}x^2 - \frac{1}{2}x + \frac{3}{4}$

$\boxed{y = (Ax + B)e^{-2x} + \frac{1}{4}x^2 - \frac{1}{2}x + \frac{3}{4}}$

Exercice 6 (suite)
Partie C : Cas où $g(x) = \alpha\cos(\omega x) + \beta\sin(\omega x)$
  1. On considère l'équation $(E) : y'' + 4y' + 5y = 2\cos(3x) - \sin(3x)$.
    1. Déterminer les réels $a$ et $b$ tels que $f_1 : x \mapsto a\cos(3x) + b\sin(3x)$ soit solution de $(E)$.
    2. Résoudre $(E)$.
  2. On considère l'équation $(E) : y'' + 4y' + 5y = \alpha\cos(3x) + \beta\sin(3x)$.
    1. Déterminer les réels $a$ et $b$ tels que $f_1 : x \mapsto a\cos(3x) + b\sin(3x)$ soit solution de $(E)$.
    2. Résoudre $(E)$.
  3. Résoudre :
    1. $y'' - 6y' + 8y = \cos x + 2\sin x$
    2. $y'' + 4y' + 4y = \sin(5x)$
Voir la solution

1.a) $y = a\cos(3x) + b\sin(3x)$

$y' = -3a\sin(3x) + 3b\cos(3x)$, $y'' = -9a\cos(3x) - 9b\sin(3x)$

Identification : $a = -\frac{1}{2}$, $b = \frac{3}{2}$

1.b) $r^2 + 4r + 5 = 0 \implies r = -2 \pm i$

$\boxed{y = e^{-2x}(A\cos x + B\sin x) - \frac{1}{2}\cos(3x) + \frac{3}{2}\sin(3x)}$

3.a) $r^2 - 6r + 8 = 0 \implies r = 2$ ou $r = 4$

Solution particulière : $y = \frac{1}{25}\cos x + \frac{7}{25}\sin x$

$\boxed{y = Ae^{2x} + Be^{4x} + \frac{1}{25}\cos x + \frac{7}{25}\sin x}$

3.b) $r^2 + 4r + 4 = 0 \implies r = -2$ (double)

Solution particulière : $y = -\frac{5}{169}\cos(5x) - \frac{12}{169}\sin(5x)$

$\boxed{y = (Ax + B)e^{-2x} - \frac{5}{169}\cos(5x) - \frac{12}{169}\sin(5x)}$

Exercice 6 (suite et fin)
Partie D : Cas où $g(x) = \mathrm{e}^{ax}$
  1. On considère l'équation $(E) : y'' - 4y' + 4y = \mathrm{e}^{-2x}$.
    1. Déterminer le réel $a$ tel que $f_1 : x \mapsto a\mathrm{e}^{-2x}$ soit solution de $(E)$.
    2. Résoudre $(E)$.
  2. On considère l'équation $(E) : y'' - 5y' + 6y = \mathrm{e}^{2x}$.
    1. Peut-on déterminer une solution particulière de la forme $x \mapsto a\mathrm{e}^{2x}$ ?
    2. Déterminer les réels $a$ et $b$ tels que $f_1 : x \mapsto (ax + b)\mathrm{e}^{2x}$ soit solution de $(E)$.
    3. Résoudre $(E)$.
  3. On considère l'équation $(E) : y'' - 4y' + 4y = \mathrm{e}^{2x}$.
    1. Peut-on déterminer une solution particulière de la forme $x \mapsto a\mathrm{e}^{2x}$ ?
    2. Peut-on en trouver une de la forme $x \mapsto (ax + b)\mathrm{e}^{2x}$ ?
    3. Déterminer les réels $a, b$ et $c$ tels que $f_1 : x \mapsto (ax^2 + bx + c)\mathrm{e}^{2x}$ soit solution de $(E)$.
    4. Résoudre $(E)$.
  4. Cas général pour $(E) : y'' + my' + py = \mathrm{e}^{ax}$ :
    1. Prouver que si $a$ n'est pas racine de $r^2 + mr + p = 0$, il existe une solution de la forme $x \mapsto A\mathrm{e}^{ax}$.
    2. Prouver que si $a$ est racine simple de $r^2 + mr + p = 0$, il existe une solution de la forme $x \mapsto (Ax + B)\mathrm{e}^{ax}$.
    3. Prouver que si $a$ est racine double de $r^2 + mr + p = 0$, il existe une solution de la forme $x \mapsto (Ax^2 + Bx + C)\mathrm{e}^{ax}$.
    4. Résoudre :
      1. $y'' - 2y' + 2y = \mathrm{e}^{3x}$
      2. $y'' + 2y' - 3y = \mathrm{e}^{x}$
Voir la solution

1.a) $y = ae^{-2x}$, $y' = -2ae^{-2x}$, $y'' = 4ae^{-2x}$

$4a + 8a + 4a = 16a = 1 \implies a = \frac{1}{16}$

$\boxed{f_1(x) = \frac{1}{16}e^{-2x}}$

1.b) $r^2 - 4r + 4 = 0 \implies r = 2$ (double)

$\boxed{y = (Ax + B)e^{2x} + \frac{1}{16}e^{-2x}}$

2.a) $r^2 - 5r + 6 = 0 \implies r = 2$ ou $r = 3$. $a=2$ est racine simple.

2.b) $y = (ax + b)e^{2x}$

$y' = (2ax + a + 2b)e^{2x}$, $y'' = (4ax + 4a + 4b)e^{2x}$

$(4a - 10a)e^{2x} = e^{2x} \implies -6a = 1 \implies a = -\frac{1}{6}$

$\boxed{f_1(x) = -\frac{1}{6}x e^{2x}}$

2.c) $\boxed{y = Ae^{2x} + Be^{3x} - \frac{1}{6}x e^{2x}}$

3.a) Non, car $a=2$ est racine double de $r^2 - 4r + 4 = 0$.

3.b) Non, on ne peut pas avec un polynôme de degré 1.

3.c) $y = (ax^2 + bx + c)e^{2x}$

On trouve : $2a = 1 \implies a = \frac{1}{2}$, $b = 0$, $c = 0$

$\boxed{f_1(x) = \frac{1}{2}x^2 e^{2x}}$

3.d) $\boxed{y = (Ax + B)e^{2x} + \frac{1}{2}x^2 e^{2x}}$

4.d-i) $r^2 - 2r + 2 = 0 \implies r = 1 \pm i$

$a=3$ n'est pas racine : $y = A e^{3x}$ avec $A = \frac{1}{5}$

$\boxed{y = e^x(A\cos x + B\sin x) + \frac{1}{5}e^{3x}}$

4.d-ii) $r^2 + 2r - 3 = 0 \implies r = 1$ ou $r = -3$

$a=1$ est racine simple : $y = \frac{1}{4}x e^x$

$\boxed{y = Ae^x + Be^{-3x} + \frac{1}{4}x e^x}$
