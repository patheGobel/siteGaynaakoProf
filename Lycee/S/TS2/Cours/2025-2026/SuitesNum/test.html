✏️ Exercices d'application :

  1. Soit \((u_n)\) définie par :

    \[ \begin{cases} u_{n+1} = \frac{1}{3}u_n + \frac{5}{3} \\ u_0 = 1 \end{cases} \]

    Montrer que \(\forall n \in \mathbb{N},\; u_n < \frac{5}{2}\).

  2. Soit \((u_n)\) définie par :

    \[ \begin{cases} u_{n+1} = \sqrt{12 + u_n} \\ u_0 = 0 \end{cases} \]

    Montrer que \(\forall n \in \mathbb{N}^*,\; 3 \leq u_n \leq 4\).

📝 Voir la correction complète

Exercice 1 : \(u_n < \frac{5}{2}\)

Montrons par récurrence que :

\(P(n) : u_n < \dfrac{5}{2}\)

🔹 Étape 1 : Initialisation

Pour \(n = 0\) :

\[ u_0 = 1 \quad \text{et} \quad \frac{5}{2} = 2.5 \]

Comme \(1 < 2.5\), on a bien \(u_0 < \dfrac{5}{2}\).

Donc \(P(0)\) est vraie.

🔹 Étape 2 : Hérédité

Soit \(n \in \mathbb{N}\) fixé. Supposons que \(P(n)\) est vraie, c'est-à-dire :

\(u_n < \dfrac{5}{2}\)

Montrons que \(P(n+1)\) est vraie, c'est-à-dire \(u_{n+1} < \dfrac{5}{2}\).

D'après la relation de récurrence :

\[ u_{n+1} = \frac{1}{3}u_n + \frac{5}{3} \]

Comme \(u_n < \dfrac{5}{2}\), on a :

\[ \begin{align*} u_{n+1} &= \frac{1}{3}u_n + \frac{5}{3} \\ &< \frac{1}{3} \cdot \frac{5}{2} + \frac{5}{3} \\ &=\frac{5}{6} + \frac{10}{6}=\frac{15}{6}=\frac{5}{2} \end{align*} \]

Donc \(u_{n+1} < \dfrac{5}{2}\).

La propriété \(P(n+1)\) est donc vraie.

🔹 Étape 3 : Conclusion

La propriété \(P(n)\) est :

  • Initialisée au rang \(n = 0\) ;
  • Héréditaire : \(P(n) \Rightarrow P(n+1)\).

D'après le principe de récurrence, on conclut que :

\(\boxed{\forall n \in \mathbb{N},\; u_n < \dfrac{5}{2}}\)

🔍 Vérification : \(u_0 = 1\), \(u_1 = \frac{1}{3} \times 1 + \frac{5}{3} = 2\), \(u_2 = \frac{1}{3} \times 2 + \frac{5}{3} = \frac{7}{3} \approx 2.33 < 2.5\)

Exercice 2 : \(3 \leq u_n \leq 4\)

Montrons par récurrence que :

\(P(n) : 3 \leq u_n \leq 4\) pour tout \(n \in \mathbb{N}^*\)

🔹 Étape 1 : Initialisation

Pour \(n = 1\) :

\[ u_1 = \sqrt{12 + u_0} = \sqrt{12 + 0} = \sqrt{12} = 2\sqrt{3} \]

Vérifions que \(3 \leq u_1 \leq 4\) :

\[ \begin{align*} 3 &\leq 2\sqrt{3} \leq 4 \\ 9 &\leq 12 \leq 16 \quad \text{(en élevant au carré)} \end{align*} \]

Comme \(9 \leq 12 \leq 16\), on a bien \(3 \leq 2\sqrt{3} \leq 4\).

Donc \(P(1)\) est vraie.

🔹 Étape 2 : Hérédité

Soit \(n \in \mathbb{N}^*\) fixé. Supposons que \(P(n)\) est vraie, c'est-à-dire :

\(3 \leq u_n \leq 4\)

Montrons que \(P(n+1)\) est vraie, c'est-à-dire \(3 \leq u_{n+1} \leq 4\).

D'après la relation de récurrence :

\[ u_{n+1} = \sqrt{12 + u_n} \]

Comme \(3 \leq u_n \leq 4\), on a :

\[ 12 + 3 \leq 12 + u_n \leq 12 + 4 \] \[ 15 \leq 12 + u_n \leq 16 \]

En prenant la racine carrée (fonction croissante sur \(\mathbb{R}^+\)) :

\[ \sqrt{15} \leq \sqrt{12 + u_n} \leq \sqrt{16} \] \[ \sqrt{15} \leq u_{n+1} \leq 4 \]

Comme \(\sqrt{15} > \sqrt{9} = 3\), on a :

\[ 3 \leq u_{n+1} \leq 4 \]

Donc \(3 \leq u_{n+1} \leq 4\).

La propriété \(P(n+1)\) est donc vraie.

🔹 Étape 3 : Conclusion

La propriété \(P(n)\) est :

  • Initialisée au rang \(n = 1\) ;
  • Héréditaire : \(P(n) \Rightarrow P(n+1)\).

D'après le principe de récurrence, on conclut que :

\(\boxed{\forall n \in \mathbb{N}^*,\; 3 \leq u_n \leq 4}\)

🔍 Vérification : \(u_0 = 0\), \(u_1 = \sqrt{12} \approx 3.464\), \(u_2 = \sqrt{12 + 3.464} \approx \sqrt{15.464} \approx 3.932\), \(u_3 = \sqrt{12 + 3.932} \approx \sqrt{15.932} \approx 3.991\)

💡 Propriété supplémentaire :

On peut également montrer que la suite \((u_n)\) est croissante :

\[ u_{n+1} - u_n = \sqrt{12 + u_n} - u_n \]

Comme \(u_n \leq 4\), on a \(\sqrt{12 + u_n} \geq u_n \iff 12 + u_n \geq u_n^2\).

Cette inégalité est vraie car \(u_n \in [3, 4]\).

Donc \((u_n)\) est croissante et majorée par 4, donc convergente.

Sa limite \(\ell\) vérifie : \(\ell = \sqrt{12 + \ell} \implies \ell^2 = 12 + \ell \implies \ell^2 - \ell - 12 = 0\).

Les solutions sont \(\ell = 4\) ou \(\ell = -3\). Comme \(\ell > 0\), on a \(\ell = 4\).

\(\boxed{\lim_{n \to +\infty} u_n = 4}\)

Outil clé Inégalité stricte Monotonie de la racine carrée
🎯 Points clés à retenir :
  • La récurrence est la méthode naturelle pour les suites définies par récurrence.
  • Il faut toujours vérifier que l'initialisation est au bon rang.
  • Dans l'hérédité, on utilise l'hypothèse de récurrence pour encadrer \(u_{n+1}\).
  • Pour les inégalités avec des racines carrées, on utilise la monotonie de la fonction.
